# v2.8.2 Canonical Firmware Version Display

## Root cause

`normalizeFirmwareVersion()` in v2.8.1 deliberately appended PDA as a fourth field whenever Samsung SmartHistory returned a normal three-part value. This produced output such as:

```text
PDA/CSC/MODEM/PDA
```

The fourth field was generated by the bot and was not required for the compact user-facing version card.

## Fix

- Three-part SmartHistory versions remain three-part.
- Legacy stored values ending in a fourth field equal to PDA are normalized back to `PDA/CSC/MODEM`.
- Missing fields are no longer fabricated.
- A genuinely distinct upstream fourth field is preserved for forward compatibility.
- The same canonical display is used in query results, administrator update cards, approved-user broadcasts, first-run baselines, reminders, pending-update panels, and flagship prompts.
- Raw Android labels such as `B(Android 16)` are displayed as `Android: 16` without changing the stored upstream record.

## Notification behavior

When an exact official firmware change is detected:

- The administrator receives the management card with old/new canonical versions, Android, build date, detection time, confirmation controls, priority controls, pause, official notes, and pending-update navigation.
- Approved whitelist users receive the compact update card without administrator controls.
- The administrator is excluded from the whitelist broadcast to prevent duplicates.
- Unauthorized chats are never broadcast recipients.
- `NOTIFY_ALLOWED_USERS_ON_UPDATE` remains enabled by default.

## Compatibility

No new Cloudflare binding, Durable Object migration, Queue, KV namespace, or Secret is required. Old cached and pending values are normalized at read/display time, so the format correction does not trigger a false firmware update.

## Official-source rules

- Exact CSC Samsung SmartHistory remains the only live authority.
- `version.xml` is not used to determine the latest firmware.
- Test, internal, generic, foreign-only, future-dated, and withdrawn records remain excluded.
