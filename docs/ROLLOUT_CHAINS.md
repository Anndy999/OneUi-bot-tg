# 发布链与多管理员

发布链用于按地区顺序监控系列固件。默认提供两条空配置链：`s26` 和 `s25`，每条链的地区顺序为韩版、欧版、港版、国行。

不会自动猜测型号或 CSC。启用前，管理员必须为每个地区添加准确的 Model / CSC；这避免错误监控或自动拼接地区。

## 配置发布链

管理员可在 Telegram 的“发布链”面板中查看状态、设置 10/15/30/60 分钟间隔、设置全天或白天监控，并启用已配置的链。

需要添加精确目标或自定义时间时，使用：

```text
/chainadd s26 kr <MODEL> <CSC> S26_KR
/chainadd s26 eu <MODEL> <CSC> S26_EU
/chainadd s25 kr <MODEL> <CSC> S25_KR
/chaininterval s26 15
/chaintime s26 08:00 23:00
/chainenable s26 on
```

`kr`、`eu`、`hk`、`cn` 分别对应韩版、欧版、港版和国行。一个 Model / CSC 不能同时加入同一系列的两个地区阶段。

首次检查只建立版本基线，不会触发发布链。之后发现真正的新版本时，机器人会向所有者和管理员发送一次确认卡片。任意一人确认后：

1. 当前地区暂停至下个月 1 日 00:00（北京时间）；
2. 同系列进入下一个地区；
3. 当 `s26` 韩版首次确认推进时，同时启动 `s25` 韩版；
4. 同一确认只能处理一次，避免多个管理员重复推进。

所有者保留最高权限，可管理管理员名单；普通管理员不能添加或删除管理员。

如果管理员已确认推进但所有者需要纠正当前地区，可使用：

```text
/chainstage s26 kr
```

该命令仅所有者可用，会将指定系列切换到已配置的地区阶段。

## 多管理员

所有者由现有的 `TELEGRAM_CHAT_ID` 决定，不会被命令删除或替换。添加管理员前，让对方私聊机器人并发送 `/whoami` 获取其 Chat ID，然后由所有者执行：

```text
/adminadd CHAT_ID 备注
```

查看或移除管理员：

```text
/admins
/admindel CHAT_ID
```

不要在聊天、代码或文档中发送 Bot Token、数据库密码或其他密钥。
