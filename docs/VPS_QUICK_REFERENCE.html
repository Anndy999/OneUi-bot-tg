OneUI VPS 快速参考

目标：VPS 长轮询、专用 PostgreSQL/Redis、systemd 自启动。无需域名、Nginx、HTTPS、443 或 Telegram Webhook。

本页不包含任何真实 Token、密码或连接字符串。初始化命令涉及 root/sudo，但本任务未执行这些系统操作。

一次性初始化

sudo bash /opt/oneui-bot/deploy/oneui-vps-bootstrap.sh

脚本创建 OneUI 专用 PostgreSQL、Redis、应用 unit，执行现有迁移并启用开机自启动。保留现有用户配置需要人工准备 Cloudflare 状态快照。

以后更新

sudo /opt/oneui-bot/deploy/update-vps.sh

检查 main、快进更新、npm ci、测试、安全检查、生产依赖 audit、只重启 oneui-bot.service，并检查健康状态。

健康与状态

curl --fail http://127.0.0.1:8787/health
sudo systemctl status oneui-bot.service --no-pager
sudo systemctl status oneui-postgresql.service oneui-redis.service --no-pager

日志

sudo journalctl -u oneui-bot.service -n 100 --no-pager
sudo journalctl -u oneui-bot.service -f

长轮询要点

  • TELEGRAM_POLLING_ENABLED=true
  • VPS_SHADOW_MODE=false
  • TELEGRAM_SEND_ENABLED=true
  • 同一 Bot Token 只能有一个轮询进程
  • 本项目不会自动修改 Webhook 状态

失败处理

更新失败时查看 systemd/journal 日志。不要 reset Git、删除用户数据、删除 Redis 数据或恢复数据库；先保留日志和备份，再选择经过批准的代码回滚或数据库恢复方案。

备份

使用 deploy/backup.sh，通过受保护的 secret store 注入 DATABASE_URL。将 PostgreSQL dump 和源代码归档复制到 VPS 外部，并定期验证可读性。数据库迁移不是普通更新的一部分，必须单独审批。
